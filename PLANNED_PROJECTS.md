# Planned Projects

A running list of potential projects/skills to add to this repo.

## Ideas

- [ ] **jira-ticket-writer**: Turns rough notes, bug reports, or feature requests into well-structured Jira tickets with a summary, description, acceptance criteria, and suggested labels/priority.
- [ ] **code-reviewer**: Reviews a diff or PR for bugs, readability, and team conventions, and leaves clear, actionable feedback.
- [ ] **release-notes-changelog**: Generates release notes and changelog entries from commits, merged PRs, or Jira tickets, grouped by features, fixes, and breaking changes.
- [ ] **feature-scaffolder**: Scaffolds the boilerplate for a new feature (files, folders, tests, and wiring) based on the project's existing patterns.
